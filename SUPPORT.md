# Support

## Usage Questions

Open a discussion or issue:

- Issues: <https://github.com/ErenAri/parallel-agents/issues>

When reporting problems, include:

- `parallel-agents --version`
- OS and Python version
- Command used
- Relevant logs or traceback

## Feature Requests

Use GitHub issues with clear problem statements and expected outcomes.

## Security Issues

For vulnerabilities, follow `SECURITY.md` and use private reporting.
